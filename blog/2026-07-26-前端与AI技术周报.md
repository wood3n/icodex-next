## 构建工具

### Webpack 5.109.0

> 参考来源：[Webpack 5.109.0 Release](https://github.com/webpack/webpack/releases/tag/v5.109.0)

Webpack 于 7 月 23 日发布 5.109.0 版本，这是近年来最重大的功能更新。`experiments.typescript` 默认开启 `"auto"`（Node.js >= 22.6 无 TypeScript loader 时自动启用），`experiments.css` / `experiments.html` / `experiments.asyncWebAssembly` 同时默认 `"auto"`。

新增 `output.html` 全套 HTML 生成选项：`title`、`meta`、`base`、`favicon`（支持多图标属性数组）、`manifest`、`csp`（注入 CSP meta 并附带行内内容哈希与 nonce）、`inline`（行内化 chunk）、`inject`（控制标签注入位置）。暴露 `injectTags` 与 `transformTags` 编译钩子，允许在构建管道中增删改 HTML 标签。

`import.meta.glob` 正式支持，含 `caseSensitive` 选项。`import.meta.env` 提供 `MODE`、`DEV`、`PROD`、`SSR`、`BASE_URL` 默认值。`import.meta.resolve("./asset")` 解析为输出资源 URL。CommonJS 模块的静态分析拼接开启，可通过 `optimization.concatenateModules: { commonjs: false }` 关闭。

新增 `output.resourceHints`（preload/prefetch/modulepreload/preconnect），默认 ESM 输出开启。CSS 原生 `@custom-media` / `@custom-selector` 解析支持。View Transition API 相关 CSS 名称作用域化支持。`?raw` / `?url` / `?inline` / `?no-inline` 资源查询后缀。支持 `cache.compression: "zstd"`。AMD 异步 externals 类型 `amd-async`。

实验性功能用户需验证 `experiments` 配置兼容性，启用 TypeScript/CSS/HTML 内置支持后可能与传统 loader 产生冲突——若已注册对应 loader，自动模式会静默回退。

### Vite 8.2.0-beta.0

> 参考来源：[Vite 8.2.0-beta.0](https://github.com/vitejs/vite/blob/main/packages/vite/CHANGELOG.md)

Vite 于 7 月 22 日发布 8.2.0-beta.0。新增 `input` 选项用于指定构建入口。CSS 模块导出 PostCSS 配置类型，支持类型安全的 PostCSS 配置文件。开发服务器网络 URL 标注网络接口名称，便于多网络环境识别。优化器支持 aube 与 nub 锁文件。更新 Rolldown 相关依赖并启用 bundled-dev 中客户端 HMR。

修复项包括：CSS chunk 在 chunk import map 中的映射（#22946）、OnceExit 注入内容中 URL 重写、HMR prune 后清除 hot data（#23002）、虚拟模块从原生配置兼容性检查中排除等。

Beta 版本不建议生产使用，可用于集成测试与插件兼容性验证。

## CSS 框架

### Shadcn/UI —— 默认迁移至 Base UI

> 参考来源：[Shadcn/UI Changelog](https://ui.shadcn.com/docs/changelog)

Shadcn/UI 于 7 月下旬完成默认组件库切换：新项目默认使用 Base UI（此前为 Radix）。Base UI 由 Radix 原团队开发，当前为 1.6.0，周下载量 600 万+。Radix 仍完全支持，现有项目不受影响。

新增 `--base aria` 选项，支持 React Aria 作为组件底层实现。`pnpm dlx shadcn@latest init --base aria` 即可初始化。新发布 `@shadcn/helpers` 开源包，首项功能为 AI SDK 与 TanStack AI 的测试辅助工具，可在不依赖模型/API 路由/网络请求的情况下模拟 `useChat` 完整生命周期。

新增 Typeset 功能，提供预设样式的 Markdown 渲染构件，支持流式输出，无需额外包或配置。

使用 `npx shadcn create` 创建项目时可选择 Base UI（默认）、React Aria 或 Radix 基座。

## 格式化与 Lint

### ESLint 10.8.0

> 参考来源：[ESLint 10.8.0](https://github.com/eslint/eslint/blob/main/CHANGELOG.md)

ESLint 于 7 月 24 日发布 10.8.0。`eslint/config` 模块新增 `ConfigObject` 类型导出，便于 TypeScript 配置文件使用。修复 `html` 格式化器中规则 ID 中保留字符的转义问题、`no-unreachable-loop` 在忽略所有循环类型时的崩溃、`prefer-object-spread` 添加括号时缺少分号。

依赖更新：minimatch 升级至 ^10.2.5。

### Prettier 3.9.6

> 参考来源：[Prettier 3.9.6](https://github.com/prettier/prettier/releases/tag/3.9.6)

Prettier 于 7 月 21 日发布 3.9.6。修复 TypeScript 接口中名为 `new` 的方法引号丢失问题。新增 `import defer` 语法支持。正式发布官方插件 `@prettier/plugin-yuku`，基于 Zig 编写的高性能 JavaScript/TypeScript 工具链 Yuku，提供 `yuku` 和 `yuku-ts` 两个解析器。

使用 Yuku 解析器需安装 `@prettier/plugin-yuku` 并在配置中指定 `parser: "yuku-ts"`，适用于对格式化速度有更高要求的项目。

### Oxlint 1.75.0

> 参考来源：[Oxlint 1.75.0](https://github.com/oxc-project/oxc/blob/main/crates/oxc_linter/CHANGELOG.md)

Oxlint 于 7 月 20 日发布 1.75.0。**破坏性变更**：AST 中 `MetaProperty` 拆分为 `ImportMeta` 和 `NewTarget`，使用 `MetaProperty` 的规则和插件需更新。新增 `node/no-top-level-await` 规则（禁止顶层 await）、`react/function-component-definition` 规则（约束函数组件写法）。`import/consistent-type-specifier-style` 新增 `prefer-top-level-if-only-type-imports` 选项。

修复 `unicorn/no-useless-undefined` 参数默认值保留、`eslint/prefer-destructuring` 类型声明处理、`eslint/no-throw-literal` 赋值错误处理、React 组件检测从返回 JSX 推断等问题。

### Oxfmt 0.60.0

> 参考来源：[Oxfmt 0.60.0](https://github.com/oxc-project/oxc/blob/main/crates/oxc_formatter/CHANGELOG.md)

Oxfmt 于 7 月 20 日同步发布 0.60.0，同样包含 `MetaProperty` 拆分的 AST 破坏性变更。新增 `preserveWhitespace` 选项，保持 tailwind CSS 类在模板表达式中的粘合。

使用 Oxlint 的用户需确认自定义规则是否依赖 `MetaProperty` 节点类型，更新相关 AST 遍历逻辑。

## AI 模型与平台

### Codex

> 参考来源：[Codex Changelog](https://developers.openai.com/codex/changelog)

**Codex CLI rust-v0.145.0**（7 月 23 日）：新增 GPT-5.9-snapshot、o3-mini、o4-mini、o4-pro、gpt-4.1 系列、gpt-4.1-nano 模型支持。新增上下文输出（context output）功能，允许 CLI 任务输出结果供后续步骤使用。新增音频输入与工具输出（支持常见本地音频格式），引入流式 Realtime V3 对话能力。（[#31327](https://github.com/openai/codex/pull/31327)、[#33261](https://github.com/openai/codex/pull/33261)、[#33856](https://github.com/openai/codex/pull/33856) 等）

**ChatGPT for iOS 1.2026.195**（7 月 20 日）：新增 Mermaid 图表在任务记录中的内联渲染、交互式表单支持；任务切换时恢复未发送的提示内容。

使用 Codex CLI 的用户可通过 `npm install -g @openai/codex@0.145.0` 升级。
